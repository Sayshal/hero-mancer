## New Features

- Hero classes with a fixed subclass lock the subclass picker to that subclass.
- Picking a hero class renames the class, uses the hero-class art, and swaps in the class and subclass features the book replaces.
- Standard classes use the WoW class badge art when the WoW Customize Classes setting is on.
- With the World of Warcraft module active, class rows on the Identity tab show a Hero class dropdown for classes that have WoW hero-class variants.
